# -AI-Tabletop-RPG-Character-Sheet-Manager-Supports-AI-Powered-TTRPG-Online-Multiplayer-Functionality
插件化应用，附带插件开发说明书
一个 Windows 桌面应用，用于管理 **COC 7th（克苏鲁的呼唤）** 和 **DND 5e（龙与地下城）** 跑团角色卡。  
支持 AI 主持跑团、角色创建向导、插件扩展、局域网联机组队。

---

## ✨ 核心功能

| 模块 | 功能 |
|------|------|
| 🃏 **角色卡管理** | 磨砂玻璃九宫格展示，点击查看/编辑详情 |
| 📥 **智能导入** | 粘贴文字自动识别角色卡，缺失字段自动填充默认值 |
| 🔍 **多维检索** | 按姓名/性别/年龄/技能/职业搜索排序 |
| 🎭 **双模式** | COC 7th / DND 5e 一键切换，数据独立存储 |
| 🌙 **深色磨砂玻璃 UI** | 类 macOS 毛玻璃效果，4 套配色主题 |
| 📤 **导出** | 选择角色导出为可重新导入的格式化文本 |
| ⚙️ **设置** | 主题切换、字体字号、插件参数配置 |

## 🤖 内置插件

| 插件 | 说明 |
|------|------|
| ✨ **角色创建向导** | 分步引导创建角色，自动掷骰、分配技能、核验规则 |
| 🤖 **AI 跑团助手** | DeepSeek AI 担任 Keeper/DM 主持跑团，支持掷骰/状态追踪 |
| 🌐 **网络联机** | 局域网 P2P 联机组队，聊天/掷骰/AI回复同步，为其他插件提供互联网接口 |
| 🔌 更多插件可自行开发 | 详见 `docs/plugin_development.md` |

## 🚀 快速开始

### 方法一：源码运行

```bash
pip install PySide6
pip install websockets    # 联机功能需要
python main.py
```

### 方法二：打包为 .exe

```bash
pip install PySide6 pyinstaller websockets
pyinstaller --windowed --onefile --name "角色卡管理器" --hidden-import websockets main.py
```

打包后在 `release/角色卡管理器.exe`，直接发给朋友使用（无需安装 Python）。

## 📖 使用指南

### 📥 导入角色卡

点击右上角 **「📥 导入」** → 粘贴文字 → 自动识别 → 确认保存

```
姓名: 张灵均，
职业: 私家侦探，
年龄: 28 ，性别: 男
力量: 60 ，敏捷: 70 ，意志: 65
体质: 50 ，体型: 55 ，外貌: 40
智力: 75 ，教育: 70
侦查: 80 ，图书馆使用: 70 ，格斗(斗殴): 60
```

> 💡 多字段可用逗号写在同一行（`姓名: xx, 职业: xx`），未填字段自动填充默认值

### 🎭 模式切换

左侧导航栏 **COC** / **DND** 切换，角色数据互不干扰。

### ✨ 创建角色

切换到 **「✨ 创建角色」** 标签页 → 6 步向导：
1. 选 COC 或 DND
2. 选职业/种族/背景
3. 掷骰生成属性（可选生成方式）
4. 分阶段分配技能（职业技能点必须用完）
5. 配置装备
6. 确认创建 → 自动保存为角色卡

### 🤖 AI 跑团

切换到 **「🤖 AI 跑团」** 标签页：

1. 首次使用：点击 **「🔑 设置 API Key」** 或在 **设置 → 插件** 中填入 DeepSeek API Key
2. 点击 **「🎲 开始冒险」**
3. 选择队伍角色（多选）→ 选择你扮演的角色
4. 选择剧本（内置 20 个 / AI 即兴创作 / 自定义）
5. 开始跑团！按 Enter 发送行动，AI 主持剧情
6. 右侧骰子面板手动掷骰，AI 根据结果展开剧情

**模型选择**：设置 → 插件 → 可选择 `deepseek-v4-flash`（快速便宜）或 `deepseek-v4-pro`（更强）

### 🌐 联机组队

切换到 **「🌐 联机」** 标签页：

**房主（主持游戏）**：
1. 输入昵称（可选）
2. 点击 **「🎮 主持游戏」**
3. 把显示的 IP 发给队友
4. 回到 AI 跑团开始冒险，AI 回复会自动同步给所有玩家

**玩家（加入游戏）**：
1. 输入昵称（可选）
2. 点击 **「🔗 加入游戏」**
3. 输入房主的 IP 地址
4. 连接后可在聊天区交流，掷骰结果全员可见

> 联机需要 `pip install websockets`，仅限局域网。

### ⚙️ 设置

侧边栏 **「⚙️ 设置」** → 两个标签页：

| 标签页 | 可设置项 |
|--------|---------|
| 🎨 外观 | 主题（深空暗黑/素白明亮/暗夜紫/森林绿）、字体、字号 |
| 🔌 插件 | AI 跑团的 API Key、模型选择；其他插件设置 |

### 🔌 插件管理

侧边栏 **「🔌 插件」** → 勾选启用/禁用插件，禁用状态重启后保持。

### 📋 版本历史

侧边栏 **「📋 版本历史」** → 查看各版本改动记录。

## 📁 项目结构

```
COC-DND-Manager/
├── main.py                      # 入口
├── character_manager/           # 核心源码
│   ├── models/                  # COC + DND 数据模型
│   ├── database/                # SQLite 数据库
│   ├── parser/                  # 文本智能解析
│   ├── ui/                      # 界面组件
│   ├── plugin/                  # 插件系统内核
│   └── paths.py                 # 路径管理（.exe 兼容）
├── plugins/                     # 📦 插件目录
│   ├── character_creator/       # 角色创建向导 v1.0.2
│   ├── trpg_ai_keeper/          # AI 跑团助手 v1.0.0
│   └── network_bridge/          # 网络联机 v1.0.0
├── docs/
│   └── plugin_development.md    # 📖 插件开发手册
├── data/                        # 数据（.exe 运行时自动创建）
│   ├── characters.db            # SQLite 数据库
│   └── settings.json            # 用户设置
└── release/
    └── 角色卡管理器.exe          # 🚀 打包好的程序
```
